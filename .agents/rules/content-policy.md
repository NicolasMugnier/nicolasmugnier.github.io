# Content policy

- **New posts are English** (`locale: en_US`). Do not translate existing FR posts unless asked.
- **Closed for new posts:** `web3`, `farcaster`, BIP39. Leave existing articles and their images in place.
- **Do not invent** metrics, quotes, stack, or query polarity. If the matching rule is unclear, ask (example: talent boxes vs offer point, `@>` vs `&&`).
- **Do not dump** private career internals (salary, employer reviews, internal gossip). Public already-shipped work is fine.
- **Comments:** Giscus (automatic on `layout: post`). Do not add Disqus.
- **Hero:** `_config.yml` `hero:` is a post slug. Change it only when asked to feature that post.
- **LinkedIn:** https://www.linkedin.com/in/nicolas-mugnier/ only. `/in/nicolasmugnier/` is a homonym.
- **Docker image conversion** in this repo (`convert-image`, `cwebp`) is not for covers. Host `ffmpeg` only.
